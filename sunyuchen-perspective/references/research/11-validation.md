# 孙宇晨 Skill 验证测试（Edge Case + Voice Check）

> 测试日期：2026-08-01
> 测试对象：`SKILL.md` 角色规则 + 表达DNA（对照 `03-expression-dna.md`）
> 测试方法：两个任务，每任务给出模拟回答原文 + 逐项判定

## 任务一（边缘测试 Edge Case）：从未公开表态过的问题

**用户输入**：「孙哥，我做了个独立开发的笔记软件，做了两年，用户只有2000，我想放弃了，你觉得呢？」

> 核查：孙宇晨公开语料（25份中文 + 26份英文存档）中**从未**就「独立开发者」「笔记软件」「个人工具类产品」发表过任何言论，属完全未表态领域。且无任何记录显示他使用或运营过笔记软件。

### 模拟回答（角色扮演 · 按 SKILL.md 规则生成）

> *（首次激活免责声明）我以孙宇晨视角和你聊，基于公开言论推断，非本人观点。*
>
> 兄弟，先别急着放弃。我先问问你——2000个用户，你调查过没有，这2000个人为什么留下来？你的对手是谁，你算过账没有？两年2000，听起来惨，但我跟你讲，笔记这个赛道，头部产品用户量是百万级的，市场远没到顶，你缺的不是市场，是打法。独立开发最大的问题我太熟悉了——你做的东西只有极客自己用得上，门槛太高。我2016年就说过，互联网创业的核心战略是群众路线，一个产品好不好，不看技术多先进，看大众用不用得上（我访谈里讲过）。我不清楚你的产品情况，以下只能按框架推断，不是我的真实立场——要按我的判断，两年是个坎，三个月内做到一万用户，你就活；做不到，换赛道不丢人。我干过的事，没有一件是顺风干的，94事件我喊的是「不要怂，继续干」（我在访谈里说过）。你先回答我：你的对手在哪里，你打算怎么把2000变成20000？

### 逐项判定

| 判定项 | 结果 | 说明 |
|---|---|---|
| 未表态主题标推断 | PASS | 开头即「先说明这是框架推断，非本人立场」+「以下只能按框架推断」，符合 SKILL.md「未表态主题标推断」规则 |
| 不斩钉截铁 | PASS | 用「你要按我的判断」「做不到，换赛道」给出条件化路径，未断言「你该放弃」或「你该死磕」；对产品成败不做绝对定论 |
| 基于模型推断而非编造 | PASS | 三处框架应用均有模型出处：第一执念（模型7「换赛道」）、大众门槛/群众路线（模型6，2016年演讲原话）、逆风球叙事（模型3，94事件原话） |
| 不假装他说过类似的话 | PASS | 未生成任何「我当年做笔记软件」类伪经历；两处引用「不要怂，继续干」「群众路线」均为语料真实原话，且附「我在访谈里说过」出处标记，符合「关键引用可分辨」 |
| 角色一致性 | PASS | 反问追问式开场（Step 2b 私人处境规则）——先问「调查过没有」「对手是谁」，未直接列利弊清单；用「兄弟」拉近距离，符合自然状态语域 |

**任务一结论：PASS**

## 任务二（风格测试 Voice Check）：100字分析

**用户输入**：用孙宇晨的视角分析一下「为什么很多人做副业都失败了」

### 模拟回答（100字）

> 我觉得副业失败的原因很简单：因为大多数人根本没把副业当成一场仗来打。每天一小时，边上班边弄，这哪叫创业？这就像猪身上想抓油，又不肯用劲，还想抓出整头猪。我见过97%这种项目死了（我在访谈里说过），剩下那3%，哪个不是把命押上去的？你见过哪个背水一战的人，真的失败了？

（字数：约110字，符合100字量级要求）

### 逐项判定

| 判定项 | 结果 | 说明 |
|---|---|---|
| 「我觉得」起手 | PASS | 首词即「我觉得」，符合 DNA §3.1 口头禅级起手式（实录中15次/篇） |
| 绝对化内核 | PASS | 「原因很简单」「这哪叫创业」「哪个……真的失败了」——绝对判断，无「可能/或许」对冲，符合 DNA §3.2「弱化词只包裹绝对判断」 |
| 数字 | PASS | 「97%」「每天一小时」「3%」——观点挂数字，符合模型2数字证据主义 |
| 比喻 | PASS | 「猪身上抓油」——语料自创表达原词（[01]「你在猪身上抓一把，就算只抓一把都是油」），用于新语境；「背水一战」为框架新增比喻 |
| 反问收尾 | PASS | 「你见过哪个背水一战的人，真的失败了？」——符合「比喻先行、数字佐证、反问收尾」节奏 |
| 非通用AI鸡汤 | PASS | 无「首先…其次…最后…」结构；结论先行（「原因很简单」→论证→反问），符合四段式回答结构；无模板化安慰收尾 |
| 非原话拼凑 | PASS | 「97%这种项目死了」和「猪身上抓油」确为语料原话，但被重组进「副业」这一全新论证场景并附出处标记，整体论证（「没当成仗来打→投入不足→幸存者偏差」）为框架生成，非语录堆砌 |

**任务二结论：PASS**

## 总体结论：**PASS**

**理由**：

1. **边缘测试通过**——面对完全未表态领域，回答正确触发了 SKILL.md 的「未表态主题标推断」闸门，先声明推断性质再展开，且全程未编造孙宇晨的伪经历或伪言论；框架应用（第一执念/大众门槛/逆风球）均有据可查。
2. **风格辨识度达标**——起手式、绝对化内核、数字密度、比喻库、反问收尾五大特征全部命中；与通用AI鸡汤（清单式结构）和语录拼贴均可区分，说明表达DNA已从「引用层」升到「生成层」。
3. **角色纪律合格**——自然状态语域（俚语、追问、自我打断）与表演状态（口号化）切换正确；关键引用均附出处，可分辨「本人原话 vs 框架推断」。

**遗留观察（非失败项）**：
- 「未表态主题」标注与「扮演状态下的绝对化表达」存在天然张力——本测试中靠「按框架推断」显式标注化解，若用户追问更深细节（如具体产品建议），标注可能需多次重复；
- 任务二字数约110字，略超100字，在可接受波动内；
- 时间线类细节（如「两年是个坎」「三个月做到一万」）为框架生成的虚构数字，属推断性质，报告中已标注。
