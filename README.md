# 网络测速（SpeedTest）

纯前端、单 HTML 文件的浏览器网络测速网站，深色现代风格，测量网络延迟、抖动、下载与上传速度。

## 运行方式

无构建步骤、无外部依赖，直接使用本地静态服务器打开：

```bash
cd speedtest
python -m http.server 8000
```

浏览器访问 <http://localhost:8000>。

也可以直接双击 `index.html` 在浏览器中打开（部分功能可能受浏览器策略限制，建议用本地服务器）。

## 功能

- 深色主题界面：灰色卡片体系 + 渐变按钮 + SVG 圆环进度
- 三大指标：Ping（延迟/抖动）、下载速度、上传速度
- 结果详情表与速度分级色条

> 当前为界面骨架版本（Task 1），测速逻辑将在后续任务中逐步实现。

## 技术说明

- 原生 HTML / CSS / JavaScript，无任何第三方库
- 测速端点：Cloudflare 公开测速接口 `https://speed.cloudflare.com/__down`（下载）与 `__up`（上传）
- 测速数据仅在浏览器本地计算，除测速流量本身外无数据离开浏览器
